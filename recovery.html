    Restore step by step

    Only if the Mac's key is lost or damaged. Your current keys are kept as a backup first, nothing is deleted.

    1. Check the recovery file above. Go on only when it says MATCHES.

    2. Keep the current key as a backup (Terminal):

      cd ~/Projects/chain-fingerprint && B="o2-keys-before-restore-$(date +%Y%m%d-%H%M%S)" && mkdir -p "$B" && cp -p o2/o2_key.pem o2/identity/me_rsa_private.pem "$B"/ 2>/dev/null; ls "$B"

    3. Put the recovery key in place. Replace PATH/TO/recovery.pem with where your copy is (drag the file into Terminal to fill in its path).

      For o²'s key (node 1):

      cp PATH/TO/recovery.pem ~/Projects/chain-fingerprint/o2/o2_key.pem && chmod 600 ~/Projects/chain-fingerprint/o2/o2_key.pem

      For your RSA key (node 2):

      cp PATH/TO/recovery.pem ~/Projects/chain-fingerprint/o2/identity/me_rsa_private.pem && chmod 600 ~/Projects/chain-fingerprint/o2/identity/me_rsa_private.pem

    4. Confirm. It should say chain intact and o² pinned:

      cd ~/Projects/chain-fingerprint && node paradox-chain.mjs verify && node paradox-chain.mjs status

    5. Refresh this site: double-click PARADOX-web.command in the chain-fingerprint folder.

    A locked (passphrase) recovery key works the same way: the chain tool asks for the passphrase each time o² signs. If you've lost the passphrase, the key can't be opened by anyone.
